# User Authentication Feature

## Project Description

A simple user authentication system built using Node.js and Express.js. The application provides user registration, login, session-based authentication, protected profile access, and logout functionality.

## Features

- User Registration
- Password Hashing using bcrypt
- User Login
- Session-based Authentication
- Protected Profile Route
- User Logout
- Error Handling

## Technologies Used

- Node.js
- Express.js
- bcrypt
- express-session
- JavaScript
